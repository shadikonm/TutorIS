# TutorIS — Неделя 7. Flutter-прототип и тестирование

**Плановый период:** 6–12 декабря 2026 года.  
**Фактическая разработка и первичная проверка:** 8 ноября 2026 года (досрочно).  
**Статус:** демонстрационный Flutter-прототип v0.1; **не** готовый production MVP.

## 1. Цель
Развернуть Flutter-среду, реализовать первые пользовательские экраны TutorIS на локальных демонстрационных данных, проверить базовые сценарии и разместить исходный код в GitHub.

## 2. Инструменты и архитектурный контекст
- IDE: Visual Studio Code.
- Flutter 3.47.9 (stable), Dart 3.13.7.
- Устройство разработчика: MacBook Air M1 (ARM64).
- Запуск: `flutter run -d chrome` (web-режим Flutter).
- Проект: `app/` в репозитории `shadikonm/TutorIS`.
- Целевая архитектура из Week 6: Flutter + FastAPI + PostgreSQL. **В Week 7 реализован только frontend-прототип на локальном состоянии.**

## 3. Реализованные элементы
| Компонент | Реализация на 8 ноября | Ограничение |
|---|---|---|
| Выбор роли | «Я ученик» / «Я репетитор» | Нет реальной авторизации и защищённых ролей |
| Кабинет ученика | Главная, расписание, задания | Демонстрационные данные |
| Кабинет репетитора | Главная, расписание, задания | Демонстрационные данные |
| Расписание | Отображение двух примеров занятий | Создание и изменение занятий не реализованы |
| Сдача работы | Кнопка «Отправить на проверку» меняет локальный статус | Нет загрузки файла или сохранения на сервер |
| Проверка работы | Репетитор переключает статус и выводится готовый комментарий | Проверка не редактируется и не сохраняется в БД |
| Смена роли | Можно переключить экран роли в одной сессии | Это демонстрация, не два независимых аккаунта |

## 5. Автоматизированное тестирование
**Команды:**
```bash
cd ~/Developer/TutorIS_repository/app
flutter analyze
flutter test
```

**Фактически полученные результаты (вывод терминала разработчика):**
- `flutter analyze`: **No issues found!**
- `flutter test`: **00:03 +4: All tests passed!**

**Тест-кейсы:**
| ID | Проверка | Результат |
|---|---|---|
| WT-01 | Стартовый экран содержит TutorIS и две роли | PASS |
| WT-02 | Ученик открывает кабинет и расписание | PASS |
| WT-03 | Репетитор открывает собственный кабинет | PASS |
| WT-04 | Работа меняет статус: отправлено → проверено, отзыв виден ученику при переключении роли | PASS |

Это **widget-тесты** одного экземпляра приложения. Они не подтверждают серверный обмен данными, разграничение доступов между реальными аккаунтами или работу на физических Android/iOS-устройствах.

## 8. Ограничения и следующие задачи
**Не реализованы:** настоящая регистрация и логин, API FastAPI, PostgreSQL, хранение файлов, приглашения по коду, реальное разграничение прав (RBAC), уведомления, редактирование расписания, полноценное мобильное тестирование, CI для Flutter.

**Следующие технические задачи:** выделить UI по модулям и моделям; согласовать API-контракты; добавить валидацию и обработку ошибок; выбрать механизм авторизации; реализовать backend по Week 6; подключить базу и хранилище файлов; добавить интеграционные и E2E-тесты; установить Android command-line tools и полный Xcode для мобильной сборки.

## 9. Итог
Результат недели — **работающий локальный Flutter-прототип, опубликованный в GitHub, с четырьмя успешными widget-тестами и без предупреждений статического анализатора на момент проверки**. Разработка MVP начата, но интегрированная информационная система пока не создана.
