### User flows
- **Репетитор:** выбор роли → регистрация → главная → расписание → новое занятие.
- **Репетитор:** главная → задания → создать ДЗ → проверить ответ.
- **Ученик:** регистрация/приглашение → главная → задание → отправка решения.

### Визуальная система
Светлая мобильная тема, фиолетовый акцент, белые карточки, базовый шрифт Inter, формат фрейма 390×844. Варианты для других размеров и доступность ещё требуют проверки.

### Что предстоит завершить
- Связать экраны Figma кликабельными переходами в режиме Prototype.
- Нарисовать альтернативные состояния: пустые списки, ошибки формы, конфликт времени, нет сети, неудачная загрузка.
- Проверить UX минимум с 3 репетиторами и 3 учениками; зафиксировать успешность и проблемы. Это **план**, тесты не проводились.
- После тестов исправить дизайн и согласовать итоговый UI.

**Граница MVP:** приложение для работы с уже существующими учениками. Каталог репетиторов и их верификация откладываются до v1.1.
