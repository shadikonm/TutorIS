# TutorIS — образовательная платформа для репетиторов и учеников

**Статус:** BA/PM-планирование и подготовка разработки. **Разработчик и владелец продукта:** [@shadikonm](https://github.com/shadikonm).

## Цель
TutorIS объединяет расписание индивидуальных занятий, домашние задания, проверку работ, прогресс и коммуникации в одном приложении для репетитора и ученика.

## Согласованная стратегия релизов
| Версия | Объём | Задачи |
|---|---|---:|
| **MVP** | Работа репетитора с существующими учениками: регистрация, роли, приглашения, расписание, перенос занятий, домашние задания, базовые уведомления и тесты | 17 |
| **v1.1** | Публичный каталог и поиск репетиторов, заявка на обучение, верификация и модерация, группы, прогресс, чат, материалы, родительский доступ | 14 |
| **v2.0** | Видеозвонки, общая доска, AI-помощник, аналитика и рекомендации | 6 |
| **Later** | Платежи, офлайн-режим, десктоп | 3 |

**Правило публикации:** регистрация репетитора не означает публичную публикацию анкеты. В v1.1 публикация в каталоге требует проверки. Проверка сочетает подтверждение личности, предметные знания, документы, демонстрационный урок и решение администратора. Педагогический диплом не обязателен для всех случаев.
